# derisk-gpui

The derisk core apps as GPUI windows, each its own Wayland client.

The core apps as GPUI windows. `--features gpui` builds the `derisk-gpui` binary.

Part of [derisk](https://github.com/losos-project/derisk), where it is built as
a member of the derisk Cargo workspace; see the README there.
