# derisk-apps

The derisk core apps, registered with mcsapi-runtime and ready for a host to launch.

Lists the core apps and registers them with mcsapi-runtime. `data/` holds their `.desktop` files. `--features preview` builds `derisk-preview`, which runs them in one window without the compositor.

Part of [derisk](https://github.com/losos-project/derisk), where it is built as
a member of the derisk Cargo workspace; see the README there.
