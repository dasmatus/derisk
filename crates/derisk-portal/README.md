# derisk-portal

The xdg-desktop-portal backend for derisk: appearance, screenshots, wallpaper and background apps.

Builds `xdg-desktop-portal-derisk`. `data/` holds `derisk.portal`, `derisk-portals.conf`, its D-Bus service and its systemd user unit.

Part of [derisk](https://github.com/losos-project/derisk), where it is built as
a member of the derisk Cargo workspace; see the README there.
